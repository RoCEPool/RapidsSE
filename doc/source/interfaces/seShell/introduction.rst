.. index::

Requirements and Dependencies
-----------------------------

SE Shell has been tested under Java runtime 11. It has not certified for
use under prior versions of Java.

Requires the RapidsSE JDBC driver, but may work against other databases if
the appropriate driver is installed and the correct JDBC URL is specified.

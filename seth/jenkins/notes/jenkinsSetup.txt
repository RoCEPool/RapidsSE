Jenkins Installation and setup

Installation
============

Adapted from: https://www.jenkins.io/doc/book/installing/linux/#red-hat-centos

Installation of the Long Term Support (LTS) release:

sudo wget -O /etc/yum.repos.d/jenkins.repo \
    https://pkg.jenkins.io/redhat-stable/jenkins.repo
sudo rpm --import https://pkg.jenkins.io/redhat-stable/jenkins.io.key
sudo yum upgrade
sudo yum install jenkins java-1.8.0-openjdk-devel
sudo systemctl daemon-reload

Create an SSH key by which jenkins will access the bitbucket repository.
Invoke ssh-keygen
save as ~/.ssh/jenkins and ~/.ssh/jenkins.pub
Set a passphrase
Copy public key and add as an access key to the repository in bitbucket:
  https://bitbucket.org/rapidsdataproject/rapidsse/admin/access-keys/

Test by executing: ssh -T -i ~/.ssh/jenkins git@bitbucket.org
More detailed instructions here: https://support.atlassian.com/bitbucket-cloud/docs/set-up-an-ssh-key/

# Make the jenkins user able to login
sudo vim /etc/password
  - change /bin/false to /bin/bash

# Setup the home directory
- sudo mkhomedir_helper jenkins
or
- copy from /etc/skel into /var/lib/jenkins 

# Set up SSH for jenkins user
ssh-keygen
cp id_rsa.pub authorized_keys
chmod 600 authorized_keys 

Edit /etc/sysconfig/jenkins
on the line starting JENKINS_JAVA_OPTIONS, add this parameter:
  -Dcom.cloudbees.workflow.rest.external.JobExt.maxRunsPerJob=64

Starting Jenkins
================

sudo systemctl start jenkins

check it with:

sudo systemctl status jenkins


Jenkins will listen on port 8080 by default

If you need to open up port 8080 on the firewall then execute the following commands:

YOURPORT=8080
PERM="--permanent"
SERV="$PERM --service=jenkins"

sudo firewall-cmd $PERM --new-service=jenkins
sudo firewall-cmd $SERV --set-short="Jenkins ports"
sudo firewall-cmd $SERV --set-description="Jenkins port exceptions"
sudo firewall-cmd $SERV --add-port=$YOURPORT/tcp
sudo firewall-cmd $PERM --add-service=jenkins
sudo firewall-cmd --zone=public --add-service=http --permanent
sudo firewall-cmd --reload
